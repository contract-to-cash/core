# 料金モデルデモ

同じ使用量に対して4つの料金モデルを並べて比較し、各モデルの計算の違いを示します。

## 実行結果

```
  Usage     Flat          Graduated     Volume        Usage-Based
  --------------------------------------------------------------
  0         ¥5000         ¥0            ¥0            ¥500
  100       ¥5000         ¥1000         ¥1000         ¥5000
  1000      ¥5000         ¥10000        ¥10000        ¥50000
  3500      ¥5000         ¥30000        ¥28000        ¥50000
  10000     ¥5000         ¥67000        ¥50000        ¥50000
```

## 料金モデル

### 定額 (Flat)
使用量に関係なく固定価格。シンプルなサブスクリプションに最適。

### 段階制 (Graduated Tiered)
各段階の使用量がその段階の単価で課金されます。所得税の累進課税に似ています。

```
3,500コール:
  段階1: 1,000 x ¥10 = ¥10,000
  段階2: 2,500 x ¥8  = ¥20,000
  合計:                 ¥30,000
```

### ボリューム制 (Volume Tiered)
総使用量がどの単価ティアに入るかで、全ユニットに単一レートが適用されます。大量利用を優遇。

```
3,500コール -> 段階2に該当
  全 3,500 x ¥8 = ¥28,000
```

### 従量制・上下限付き (Usage-Based with Min/Max)
単位あたり価格に下限と上限を設定。最低収益と顧客のコスト上限を保証。

```
¥50/GB, 下限 ¥500, 上限 ¥50,000

    3 GB -> ¥150 -> 下限適用 ¥500
  100 GB -> ¥5,000               (通常)
2,000 GB -> ¥100,000 -> 上限適用 ¥50,000
```

## 主要コンセプト

| コンセプト | 説明 |
|-----------|------|
| **PricingModel インターフェース** | `CalculatePrice(usage int64) Money` -- 全モデルが1つのインターフェースを共有 |
| **FlatPrice** | 使用量無視、固定額を返却 |
| **TieredPrice** | 段階制とボリューム制の両方をサポート |
| **UsagePrice** | 単位あたり課金（任意の上下限付き） |
| **合成可能** | 任意のモデルをPlanに割当可能。使用量メトリクス毎に異なるモデルを混在可能 |

## 実行

```bash
go run ./examples/pricing-models-demo/
```
